# inbox-triage-SOP.md — Clearing the Download Inbox

> ~2,100 files sit in `~/Downloads/_Inbox/`, already sorted by type (PDFs, Documents, Images, Spreadsheets, Keys & Certs, Presentations, etc.). Don't bulk-move. Process in slices.

1. Pick ONE type folder per session (e.g. `Documents`). Don't open everything at once.
2. Scan filenames only. Group by obvious owner: Ola's CVs/certs → `Reference/Career & Credentials`; property/AST/completion → `Engine/Property Deals`; Airbnb/SA → `Engine/Airbnb Audit Tool`; bills/payslips → `Reference/Admin & Finance`; personal/family letters → `Reference/Personal & Family`.
3. Other people's docs (not Ola's) and one-off junk → leave for `~/Downloads/_Review-Delete/`, don't file into the vault.
4. Move with `mv -n` (never overwrite). Append every move to `~/Knowledge/move-log.txt` with a date stamp.
5. When in doubt, leave it where it is. A misfile is worse than a delay.
6. Big media (photos/video) never enters the vault — route to `~/Media/`.
7. Stop when the slice is clear. One clean type folder per session beats a half-done sweep.
