# vault-map.md — How to Navigate This Vault

> The master table of contents for `~/Knowledge/`. Any AI reads this to find the right folder fast
> instead of scanning everything. Updated: 2026-06-22.

## The framework: ACE

| Folder | Holds | Rule |
|--------|-------|------|
| **Reference/** | Static knowledge, reference, credentials | Things I refer back to. Small files. |
| **Calendar/** | Time-anchored notes — daily logs, meetings | Only dated material. |
| **Engine/** | Active projects, things in progress | Where live work lives. |
| **Sorting Tray/** | Unsorted / uncertain | Default dumping ground. Process from here. |
| **Library of Tools/** | AI layer — this map, mi.md, skills | Keep AI-generated content isolated here. |
| **Archive/** | Cold storage | Finished, retained for reference. |

## Map

### Reference (reference knowledge)
- `Career & Credentials/` — CVs · Certificates (SWQR, gas certs) · PMP · Highways & Streetworks (TfL history) · DevOps · Employment Records
- `Business & Systems/` — Brand Assets (logos)
- `Property & Airbnb/` — HMO/short-let reference, guest docs
- `Templates & Reference/` — OneNote templates, reusable docs
- `Admin & Finance/` — bills, council tax, energy, payslips
- `Personal & Family/` — Immigration & Legal · Family · Letters & Correspondence · Relocation

### Engine (active projects)
- `RevenueDrive/` — Systems With Melly build: Systems Business, Sales, VAs, business plan
- `Property Deals/` — one folder per address (114 Malmstone Ave, Flat 2 25 Brookhill Rd, Wordsworth, Bridging Contract Docs, Maria St)
- `Airbnb Audit Tool/` — Al Airbnb files, SA Up North
- `Mr Melly Site/` — reserved for the live site repo (repo itself stays at `~/Desktop/Mr Melly/` — link, don't move a git project in)

### Calendar (time-based)
- `Daily/` — daily notes / logs
- `Meetings & Logs/` — meeting records, LinkedIn activity export

### Outside the vault (deliberately)
- `~/Media/Photos` + `~/Media/Video` — all photos and video (incl. Zoom recordings). Never in the vault.
- `~/Downloads/_Inbox/` — single dumping ground, sorted by type (PDFs, Images, Documents, Spreadsheets...). Triage from here.
- `~/Downloads/_Review-Delete/` — staged junk + duplicates awaiting a final glance before binning.
- `~/Downloads/_Archive-YYYY/` — annual sweep of old downloads.

## Conventions
- Keep it flat. Avoid deep nesting.
- New, unsure note → `Sorting Tray/`. Link liberally with `[[note name]]`; once well-linked, exact folder matters less.
- Big media never enters `~/Knowledge/`.
